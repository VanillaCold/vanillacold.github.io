About Wiimote Mouse

Wiimote Mouse is a project to allow the use of a Nintendo Wii Remote as a pointer device for Windows or Linux.
Although its practical uses are limited, there are some.
For instance, a home-theatre PC used for streaming might benefit from being controlled with a remote, such as a wii remote!

Of course, I didn't think of the practical uses when I started down this project, I just wanted to mess around
and see what was possible with a library I found.

Features


Current Functionality

  • Left, right and middle mouse buttons, mapped to A, B and 1 respectively.
  • Scrolling, using up and down on the directional pad.
  • IR cursor pointing, with rudimentary stabilization
  • A custom Wii Remote cursor that rotates with the remote, as in the Wii Menu

Planned & In-Progress Features

  • A settings menu, styled after the Wii's Home Menu and accessed by pressing the Home button
  • Screen calibration settings
  • An option to use the regular cursor instead of the Wii Remote cursor
  • Gamepad support; use a Wiimote and Nunchuck as a gamepad w/ gyro support on, for instance, Steam Input
